# 简介模块

展示真实学生资料、简介、邮箱、ORCID 与用户维护的个人图片。

- 入口：`#about`。
- 文件：`section.html` 为简介片段，`styles.css` 管分栏与手机布局，`module.js` 注册分区，`images/portrait.jpg` 为用户维护的独立图片。
- 接口与边界：通过 `registerSection({ id: "about" })` 登记；进入动画由共享服务处理，模块没有跨功能数据读取。
- 粒子接入：本模块维护纯黑 `#000` 背景，在根节点声明公开 `data-particle-surface="black"`，标题与内容容器声明 `data-particle-foreground`。粒子服务仅接入这些公开边界，裁剪图片区域，背景颜色及布局仍由本模块负责；不可把这个标记放在图片背景上。
- 维护：修改资料编辑片段；用户提供的 ORCID 为 `https://orcid.org/0009-0005-6858-4000`，与联系区明确重复展示，不据此补写未经提供的个人经历。替换个人图片时同步英文替代文本及署名页。当前片段的 `portrait.jpg?v=cc79adfc8573` 使用图片内容 SHA256 前 12 位作为缓存键；以后换照片需重新计算并更新 `?v=` 后装配，缓存键不修改图片原文件字节。更新重复出现的身份资料时显式核对首页和联系区。
- 验证：[兼容性测试记录](../../docs/modules/about.md)；资料变更时运行 `npm run test:academic-profile` 检查 ORCID 展示、外链、键盘与手机布局，再回归分栏、图片裁切、邮箱及相邻首页。三内核/三视口共 72 流程为 2026-10-10 资料更新的历史证据，不能替代本次样式验证；外链目标和属性核对不等于访问外站。

本说明使用中文；片段和数据中的网页文字使用英文。修改源文件后装配，不手改根目录生成页面。

- 桌面改为接近等宽的人像与简介双栏；人像采用 20px 圆角，资料使用石墨灰分组卡片，补充说明保留独立的轻边线。
- 保留当前用户已替换的 `portrait.jpg` 原字节，仅按观察更新图片尺寸和英文替代文本，移除旧“待换人像”占位说明。图片观察到户外人物、湖面、树与塔，不据此推断身份、地点、拍摄者或来源；Home 仍独立使用原山水图。

- 2026-10-23 在 Codex 应用内浏览器预览 1440×900 简介及 320×780 人像和资料卡；工具未提供内核及精确版本，窄屏为模拟视口。其他内核、真机与原生减少动态偏好未测试，详见[本轮测试记录](../../docs/modules/about.md)；此前 72 流程属于历史资料更新证据。

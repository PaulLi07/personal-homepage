# 论文成果详情

展示真实论文或成果条目，尚无资料时保持空状态。

- 入口：`#academic/publications`，也可从父区照片或缩略图进入。
- 文件：`content.js` 保存英文论文介绍与 `entries`；`images/cover.jpg` 保存本栏目封面。
- 接口：通过 `Homepage.registerDetail("academic", "publications", data)` 独立注册；渲染、切换、路由与关闭由共用详情服务负责。
- 维护：添加真实条目时保持数组格式；替换封面需同步英文替代文本、署名和父区入口。受影响位置：父区论文缩略图与预览；联系背景为独立副本，不随此图片替换。
- 边界：不读取兄弟模块内部，不在本文件实现另一套弹窗。
- 验证：[测试记录](../../../docs/modules/academic-publications.md)；检查对应入口、切换、直接详情链接、空状态与图片。

本说明中文，所有网页呈现数据英文。没有用户提供的内容时保持 `entries: []`，不要编造。

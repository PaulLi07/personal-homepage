# 已发表论文分类

入口为 `#academic/publications/published`，`data.js` 独立登记 Published 分类说明及论文条目，格式见[父模块说明](../README.md)。

尚未提供已发表论文资料，`entries` 保持空数组。维护时核对正式发表记录、日期及原始链接，不能仅凭 arXiv 预印本推断发表状态。

说明中文、网页英文。运行 `npm run test:academic-profile` 实测目录点击、直达、刷新、返回、英文空状态及窄屏布局，结果由[Publications 记录](../../../../docs/modules/academic-publications.md)统一登记；本轮三内核/三视口、共 72 流程通过，具体分类覆盖见统一记录；不把外链属性核对视为已访问外站。

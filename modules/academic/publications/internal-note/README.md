# 内部材料分类

入口为 `#academic/publications/internal-note`，`data.js` 独立登记 Internal note 分类说明及条目，格式见[父模块说明](../README.md)。

目前没有用户提供的公开材料，`entries` 保持空数组。只添加已经允许公开的真实材料及 HTTPS 原始记录链接；受限内部文档不得上传公开仓库，也不应以公开链接冒充访问控制。

说明中文、网页英文。运行 `npm run test:academic-profile` 实测目录点击、直达、刷新、返回、英文空状态及窄屏布局，结果由[Publications 记录](../../../../docs/modules/academic-publications.md)统一登记；本轮三内核/三视口、共 72 流程通过，具体分类覆盖见统一记录；不把外链属性核对视为已访问外站。

# 学术经历详情

展示已确认的学术身份，并为未来补充真实学术经历保留入口。

- 入口：`#academic/experience`，从学术区的 Experience 缩略图进入。
- 文件：`content.js` 保存英文身份介绍、资料和 `entries`；`images/cover.jpg` 保存本栏目封面。
- 接口：通过 `Homepage.registerDetail("academic", "experience", data)` 独立注册；渲染、切换、路由与关闭由共用详情服务负责。
- 内容边界：仅确认南开大学研究生、理论物理领域；经历列表暂时为空，不填入未经确认的时间、职务、奖项或成果。
- 维护：用户提供真实经历后再补充条目；替换封面需同步英文替代文本、署名和父区入口。
- 边界：不读取兄弟模块内部，不在本文件实现另一套弹窗。
- 验证：[测试记录](../../../docs/modules/academic-experience.md)；改名后重新检查入口、预览、切换、直接详情链接、空状态与图片。

本说明中文，所有网页呈现数据英文。没有用户提供的内容时保持 `entries: []`，不要编造。

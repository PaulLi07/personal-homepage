# 人物动作素材库

## 设计方案与职责

人物外壳从32×38px调整为40×46px，保持白色漫画线描。所有动作共用一副SVG骨架、同一自然站姿和脚底y=0基线；每段动作平滑进出，片段结束先收步/收手，再继续下一段。走到边缘先停稳，选中下一段行走时插入转身，转身完成才反向起步。以条件加权抽取避免机械循环。

| 文件 | 职责 |
|---|---|
| `clips.js` | 动作素材、时长范围、共同站姿及关节采样；不操作DOM或时钟 |
| `director.js` | 加权抽取、不连续重复、转身衔接、位移和缩放；纯时间轴，无DOM |
| `figure.js` | 将采样姿态绘制成SVG；不处理随机、计时或根位移 |
| 上级 `walker.js` | 挂载、30fps绘制上限、可见性/详情/动态偏好暂停及卸载 |
| 上级 `config.js` | 人物尺寸、速度、动作权重和节奏配置 |

## 动作集合

| 标识 | 动作 | 基础时长 | 默认抽取权重 |
|---|---|---|---|
| `walk` | 行走 | 5–8.5秒，窄路段按距离调整、至少1秒 | 45 |
| `idle` | 自然站立、轻微呼吸 | 1.6–2.8秒 | 12 |
| `look` | 抬头观察 | 2.6–3.8秒 | 16 |
| `think` | 托手思考 | 2.6–4秒 | 12 |
| `stretch` | 伸展双臂 | 3–4.2秒 | 9 |
| `wave` | 轻轻挥手 | 2.2–3.2秒 | 6 |
| `turn` | 站稳转身 | 默认0.9秒 | 连接片段，不独立随机抽取 |

权重不是最终播放比例：相邻动作不重复，最多连续两段静态动作后会恢复行走；边缘必须先转身。窄路径仍可播放全部静态素材，避免陷入行走/转身的循环。素材中的时长为基础范围，`durationScale`统一调整静态与请求的步行时长，步行还受路径和目标速度约束。

## 衔接和配置

动作在起点/终点返回完全相同的站姿，使用五次缓动使边界速度平顺；行走采用整数步态周期，并让身体位移和动作幅度共同渐入/渐出。静态动作固定脚底和人物地面位置。动作进度与可见墙钟分开，离屏、后台、详情、减少动态效果及页面离开时取消动画帧并冻结片段，恢复后从原进度续播。

集中调整 `../config.js` 的 `walker`：

- `heightPx:46`：外壳高度，宽度按40:46保持比例；挂载时限制32–72px，粒子排除路径高度随尺寸扩展。
- `speedPxPerSecond:24`：目标行走速度，短路径自动减速。
- `stepDurationMs:850`：步态周期参考值；整段按整数周期取整。
- `durationScale:1`：时长倍率；`turnDurationMs:900`：转身时长。
- `weights`：六个日常动作的抽取权重，以这里的配置为准；全零或异常配置有安全回退。

素材姿态的关节坐标以双脚中心为原点，使用统一的hip/shoulder/head与前后肘、手、膝、脚。画幅为 `-20 -46 40 46`，伸展与挥手保持在画幅边界内。新增素材需登记时长和采样分支，保证两端共用站姿、无脚底穿地；同步导演的可选动作/默认权重、配置及相应测试，不能直接拼接另一套人体坐标。

## 接口与验证

命名空间 `Homepage.academicExploration.character`：

- `sampleClip(id,progress,{cycles})`：返回独立关节数组，未知动作/坏数值回退站姿。
- `createDirector({width,config,random})`：返回 `advance(deltaMs)`、`getFrame()`、`resize(width)`；帧含 `pose,x,facing,action,progress`，width是扣除人物自身宽度后的可走距离。
- `createFigure()`：返回 `element`、`render(frame)`、`destroy()`；页面由父挂载器负责定位。

`npm run test:walker-actions`验证素材、片段连续性、抽取、边缘与长时钟；`npm run test:walker-lifecycle`验证暂停、恢复、缩放与清理；`npm run test:academic-scene`回归既有图窗/入口。离线测试不能替代真实浏览器观感，实测范围见 [本轮记录](../../../../docs/modules/academic.md#walker-actions-2026-10-23)。

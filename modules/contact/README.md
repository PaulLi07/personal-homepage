# 联系模块

提供邮箱、GitHub、ORCID、学校资料、年份及署名页入口。

- 入口：`#contact`。
- 文件：`section.html` 保存联系区与页脚，`styles.css` 管布局，`module.js` 管年份更新，`images/background.png` 保存用户提供的蓝色夜景原图。
- 接口与边界：注册 `contact` 分区，在初始化传入的 `root` 内更新年份；导航回顶使用共享导航，不读取其他模块。
- 维护：修改链接与资料编辑片段；ORCID 使用用户提供的 `https://orcid.org/0009-0005-6858-4000`，与 About 一并核对，外链采用新标签页及 `noopener noreferrer`。背景可单独替换，同步英文署名及素材说明。更新年份逻辑只处理本模块节点。
- 当前原图为 3024×1964 PNG，保留用户附件的原字节；CSS 用覆盖布局、焦点位置和轻微暗部渐变保证文字可读，未裁剪或重新编码文件，不标记为粒子表面。原作者 / 来源待用户补充，不称为本人摄影；网页署名信息见独立 Image credits 页。
- 验证：[兼容性测试记录](../../docs/modules/contact.md)；2026-10-11 背景替换使用 `test:particles` 与 `test:compat` 验证原图、粒子零覆盖、桌面 / 手机可读性、邮箱、GitHub、ORCID、年份、署名页和回顶。此前资料更新的 72 流程为历史证据；外链仅核对目标和属性，测试不访问外站。

本说明使用中文；片段和数据中的网页文字使用英文。修改源文件后装配，不手改根目录生成页面。

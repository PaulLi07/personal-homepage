# 创作详情

为个人创作及其介绍保留位置，当前使用湖泊占位图，尚无真实作品条目。

- 入口：`#life/creations`，从生活区的 Creations 照片进入。
- 文件：`content.js` 保存英文创作介绍和 `entries`；`images/cover.jpg` 保存本栏目封面。
- 接口：通过 `Homepage.registerDetail("life", "creations", data)` 独立注册；渲染、切换、路由与关闭由共用详情服务负责。
- 维护：用户提供真实作品后再补充条目；替换封面同步英文替代文本、署名和父区入口。生活区背景仍使用父模块自己的独立图片。
- 边界：不读取兄弟模块内部，不在本文件实现另一套弹窗。
- 验证：[测试记录](../../../docs/modules/life-creations.md)；改名后重新检查入口、切换、直接详情链接、空状态与图片。

本说明中文，所有网页呈现数据英文。没有用户提供的内容时保持 `entries: []`，不要编造。

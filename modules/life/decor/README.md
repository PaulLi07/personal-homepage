# Life 摄影手账装饰

为拍立得照片堆增加右上回形针与左下卷曲胶片，灰白线稿只作构图补充。模块无脚本、状态、路由或公开业务接口，不改变照片选择、详情与作者功能。

| 文件 | 职责 |
|---|---|
| `styles.css` | 装饰位置、尺寸、层级及手机隐藏规则 |
| `paperclip.svg` | 银白双线回形针，透明背景 |
| `film-strip.svg` | 灰白卷曲胶片线稿，格内及周围透明 |

父 `section.html` 放置两个 `aria-hidden="true"` 的装饰节点：回形针位于 Travels 的 `.life-paper` 内，随该照片层级与纸面微抬一起移动；胶片位于 `.life-stack__stage` 内，处于全部照片后方。`app/site.json` 在照片堆样式之后装配本目录 CSS；父胶水及照片堆控制器无须接入。

位置、转角及 `--clip-height` / `--film-width` 都在本目录 CSS 调整。桌面回形针高50px，胶片宽110–140px；≤760px只保留36px回形针并隐藏胶片。装饰静止，不新增循环或悬停动画。更换图形直接编辑原生SVG，不转换为带底色的位图。

所有装饰不接收指针事件，也不进入辅助技术朗读或键盘顺序。透明SVG以CSS背景放在Life既有前景内，采用与Academic透明造景相同的例外：不为装饰新增矩形 `data-particle-exclude`，让空隙透出粒子；普通照片与白色纸边仍保留原有粒子排除。装饰不得覆盖可触达露边、黄色标题或下方语录。

修改后装配并检查，再实际预览桌面与窄屏，核对胶片的隐藏阈值、回形针跟随层级、四入口悬停/点击/键盘、无横向溢出及透明粒子边界。本轮实测范围与限制统一记在[Life记录](../../../docs/modules/life.md#life-photo-decor-2026-10-25)，不沿用此前照片尺寸版本的结论。

任务分支 `style/life-photo-decor`；回退分支 `backup/pre-life-decor-2026-10-25` 保留 `52208fa`。恢复前保存当前工作和用户未提交图片；不硬重置、不自动推送。

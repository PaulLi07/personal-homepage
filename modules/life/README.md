# 生活概览模块

用一组轻微不规则交叠的横向拍立得照片，提供 Moments、Travels、Creations、Relationship 四个生活栏目入口；黑底与照片堆下方的白色手写语录共同构成生活区。

- 入口：`#life`；详情为 `#life/<栏目>`，旧路由别名继续保留。
- 文件：`section.html` 保存英文标题、四个照片按钮与语录；`styles.css` 只管理本区黑色画布、标题、留白和语录。`stack/` 独立维护拍立得配置、交互、构图、字体与说明，父 `module.js` 仅注册分区、挂载与清理。四个内容子目录各自维护内容和封面。
- 当前构图：取消旧的整区白色主框/副框。各照片改为直角白色纸边，图像约3:2，底边留出手写标签。固定底座，转角收敛到约±2–3°，位置更均匀但保留交错叠放。当前桌面舞台最大1100px、比例1100:720，单卡宽55%；手机单卡宽80%、舞台仍为1:1.3，不再采用旧错落双列。1440px视口下单卡约605px，较初版499px放大约21%；手机较原76%宽放大约5%。调整时保留四卡外露入口及下方提示的留白。
- 交互：鼠标悬停置顶并同步亮黄色花体标题，离开保留最后选择，点击进入；键盘聚焦置顶，Enter/Space进入。触摸/笔先点下层照片只选中，再点正面进入；当前正面照片可直接进入。键盘焦点留在卡片上时优先于其它卡片悬停，失焦或指针按下后交还鼠标。无自动洗牌或滚动漂移；减少动态效果取消抬升与过渡。
- 接口与边界：分区初始化接收 `{ root, details, reducedMotion }`，通过 `Homepage.lifeStack.mount()` 挂接照片堆；详情仍调用公开 `details.open("life", key, { trigger, source })`。博客、作者发布、Relationship密码及私密内容不进入照片堆控制器。
- 字体：全站普通信息继续用正常系统字体；本区黄色涂鸦标题、照片纸边标签和白色语录是用户批准的局部手写字体例外。Kaushan Script与Caveat仅从本地 `stack/fonts/` 加载，不请求远程字体；随源码保留SIL OFL 1.1原始版权/许可，来源和完整性见[字体说明](stack/fonts/README.md)。
- 粒子：根节点以 `data-particle-surface="black"` 声明纯黑 `#000`；普通 `.life-frame` 为前景。仅各照片按钮及白色纸边声明 `data-particle-exclude`，整个照片堆和透明间隙不排除。标题不截获指针，照片不受粒子覆盖；不更改粒子服务。
- 锚点：沿用公开 `--navigation-height` 加16px，正常导航后核对标题与首张照片不被固定栏遮挡，不读取导航私有结构。
- 内容维护：换封面编辑对应栏目 `images/cover.jpg`、英文替代文本及来源记录；四张封面互不联动。语录编辑父片段，标题编辑 `stack/config.js` 并同步片段静态回退。Moments独立保存文章、读者和作者发布；Relationship独立保存密文与解锁，公开封面不受访问密码保护，私密文件不能放入公共封面目录。
- 缓存：Moments的 `posts.js` 仍由清单 `liveScripts` 保持原URL；照片堆脚本与样式按装配内容版本加载。完整源码更新后装配并刷新用户原预览标签，不手改生成页面。
- 验证：运行 `npm run test:life-stack`、装配和检查，再实测桌面/窄屏四张外露可触达、置顶不抖动、最长标题、鼠标/键盘/真实触摸、详情与历史、减少动态效果、无横向溢出及粒子边界。离线输入序列测试不能证明真实触摸或浏览器绘制，实际记录见[Life测试记录](../../docs/modules/life.md)。
- 分支与回退：当前尺寸微调在 `style/life-larger-polaroids`，`backup/pre-life-sizing-2026-10-25` 保留调整前 `d9dae2d`；只改尺寸、坐标与转角，交互不变。初版 `feat/life-polaroid-stack` 及 `backup/pre-life-polaroids-2026-10-25`（`0783998`）继续保留。维护先保存当前及未提交的人像等资料，再选用备份；不硬重置、不自动推送，发布需用户具体授权。

详细参数与接口见[照片堆说明](stack/README.md)。所有说明使用中文，网页文字与无障碍标签使用英文。

## 历史：2026-10-23 样式更新

以下为旧相框版本的记录，外观及测试不能作为当前拍立得版本的要求或证据。

依照已批准的 Apple 风格方案统一相框圆角、照片字幕基线与空隙，减小照片旋转并保留错落感、3px 主框和 2px 副框。照片使用轻阴影，标题采用正常字形与克制字号；没有替换素材、内容、数据或四个栏目路由。

2026-10-23 在 Codex 应用内浏览器预览 1440×900 生活区并逐一点击四个详情，另查看 320×780 和 820×1180 布局；431×767 正常导航后导航底为 104px、相框顶为 131.84px、标题顶为 196.84px，未遮挡。工具未提供内核及精确版本，窄屏为模拟视口；未测其他内核、真机和原生减少动态偏好，详见[本轮 Life 测试记录](../../docs/modules/life.md)。

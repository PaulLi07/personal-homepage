# 生活概览模块

展示散落照片与 Moments、Travels、Creations、Relationship 四个生活栏目的入口。

- 入口：`#life`；详情为 `#life/<栏目>`。
- 文件：`section.html` 保存照片按钮，`styles.css` 管纯黑背景、白色相框、照片轮廓与手机布局，`module.js` 管本区点击及照片漂移。四个子目录各自维护内容与封面；原整区背景已从当前目录移除，历史保留在 Git 与回退包。
- 接口与边界：注册 `life` 分区，初始化接收 `{ root, details, reducedMotion }`；通过详情服务打开栏目，只查询本区元素。减少动态效果时应停止照片漂移。
- 布局与粒子：根节点用 `data-particle-surface="black"` 声明 `#000`。普通 `.life-frame` 外层为前景，主框与四张 `.life-image` 使用 3px 亮白边，偏移副框使用 2px 较淡白边，形成前后层次；主框无整体变换，圆角 20px，照片圆角 18px。桌面保留散落布局，旋转收敛到约 ±2–2.5°；手机改为错落双列，沿用 6px 主副框偏移及 5px 照片副框偏移控制外沿，框内黑底继续显示粒子。仅照片按钮声明 `data-particle-exclude`，不排除整个框；原绝对定位组件不直接添加前景属性。
- 锚点留白：`#life` 的 `scroll-margin-top` 使用导航公开的 `--navigation-height` 加 16px 留白，避免点击导航后白框顶与标题被固定栏遮挡；不读取导航私有节点，也不改变自然滚动和详情关闭的位置恢复。
- 扩展：Moments 独立保存博客数据、读者视图与作者发布；Relationship 独立保存密文和解锁逻辑。公开封面不受访问密码保护；私密内容不能放在通用 content.js 或 images/ 中。
- 缓存边界：清单的 `liveScripts` 声明 Moments `posts.js` 保持原 URL；其他脚本及样式装配为内容版本 URL。浏览器直接发布文章不要求重新生成整页，完整源码更新仍须装配并刷新实际预览。
- 维护：改故事与照片编辑对应子目录；增加栏目时补本区入口和样式，并声明内容脚本。封面互不联动；新增非 `img` 的图片或视觉容器须显式排除，不重新启用整区图片背景。
- 验证：[兼容性测试记录](../../docs/modules/life.md)；改动后关注四栏目入口、白框与叠层、手机照片点击及无横向溢出、详情与减少动态效果，以及框内黑区白点和图片零覆盖。本轮完整页面实测由对应记录登记，不能沿用此前图片背景的结论。

本说明使用中文；片段和数据中的网页文字使用英文。修改源文件后装配，不手改根目录生成页面。

## 2026-10-23 样式更新

依照已批准的 Apple 风格方案统一相框圆角、照片字幕基线与空隙，减小照片旋转并保留错落感、3px 主框和 2px 副框。照片使用轻阴影，标题采用正常字形与克制字号；没有替换素材、内容、数据或四个栏目路由。

2026-10-23 在 Codex 应用内浏览器预览 1440×900 生活区并逐一点击四个详情，另查看 320×780 和 820×1180 布局；431×767 正常导航后导航底为 104px、相框顶为 131.84px、标题顶为 196.84px，未遮挡。工具未提供内核及精确版本，窄屏为模拟视口；未测其他内核、真机和原生减少动态偏好，详见[本轮 Life 测试记录](../../docs/modules/life.md)。

# 首页模块

展示学术身份、欢迎语与山水摄影背景，引导访客进入简介或学术区。

- 入口：`#home`。
- 文件：`section.html` 为首页片段，`styles.css` 管首屏及背景布局，`module.js` 注册分区，`images/hero.jpg` 保存背景。
- 接口与边界：通过 `registerSection({ id: "home" })` 登记，无业务初始化；导航与开场由共享层提供。首屏与简介的连续背景布局由页面外壳明确组合，不直接读取简介内部。
- 维护：修改身份与欢迎语编辑片段；换背景替换本模块图片，同步英文署名和素材说明。修改首屏高度时回归相邻简介区。
- 当前背景按用户要求使用 About 山水照片的独立副本，`hero.jpg` 与来源原图字节相同；网页仍引用本模块资源，可分别替换，不在运行时读取 About 内部路径。英文署名为 Ivan Rohovchenko / Unsplash，图片背景不标记为粒子表面。
- 验证：[兼容性测试记录](../../docs/modules/home.md)；改动后关注首屏文字和图片、两个入口、滚动至简介及其连续背景。

本说明使用中文；片段和数据中的网页文字使用英文。修改源文件后装配，不手改根目录生成页面。

# 首页模块

展示学术身份、欢迎语与山水摄影背景，引导访客进入简介或学术区。

- 入口：`#home`。
- 文件：`section.html` 为首页片段，`styles.css` 管首屏及背景布局，`module.js` 注册分区，`images/hero.jpg` 保存背景。
- 接口与边界：通过 `registerSection({ id: "home" })` 登记，无业务初始化；导航与开场由共享层提供。首屏与简介的连续背景布局由页面外壳明确组合，不直接读取简介内部。
- 维护：修改身份与欢迎语编辑片段；换背景替换本模块图片，同步英文署名和素材说明。修改首屏高度时回归相邻简介区。
- 历史上背景曾从 About 的原山水照片复制；当前 Home 独立保留该山水 `hero.jpg`，About 已由用户换为人像，两者不再要求相同。网页始终引用本模块资源，不在运行时读取 About 内部路径。英文署名为 Ivan Rohovchenko / Unsplash，图片背景不标记为粒子表面。
- 验证：[兼容性测试记录](../../docs/modules/home.md)；改动后关注首屏文字和图片、两个入口、滚动至简介及其连续背景。

本说明使用中文；片段和数据中的网页文字使用英文。修改源文件后装配，不手改根目录生成页面。

## 2026-10-23 设计调整

- 保留独立山水背景及原署名；使用克制的明暗渐变提升文字可读性，不修改原图，不接入粒子。
- 桌面为身份标题与欢迎语双栏，姓名标题最大 60px；手机改为单栏，并为共享 `--navigation-height` 留出空间。按钮取消重复翻滚文字，采用 12px 圆角与清楚的主次对比。
- 首页入场位移收敛为 22px，减少动态效果继续由共享偏好规则处理；`#home`、`#academic`、`#about` 及原资源路径保持。
- 2026-10-23 在 Codex 应用内浏览器完成 1440×900、390×844、320×780 首屏预览，并检查主按钮的 Tab 焦点。工具未提供内核及精确版本；手机尺寸为模拟视口，其他内核、真机和原生减少动态偏好未测试，详见[本轮测试记录](../../docs/modules/home.md)。

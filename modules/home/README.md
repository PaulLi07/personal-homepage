# 首页模块

展示学术身份、欢迎语与舷窗地球摄影背景，引导访客进入简介或学术区。

- 入口：`#home`。
- 文件：`section.html` 为首页片段，`styles.css` 管首屏及背景布局，`module.js` 注册分区，`images/hero-earth-window.jpg` 保存背景。
- 接口与边界：通过 `registerSection({ id: "home" })` 登记，无业务初始化；导航与开场由共享层提供。首屏与简介的连续背景布局由页面外壳明确组合，不直接读取简介内部。
- 维护：修改身份与欢迎语编辑片段；换背景替换本模块图片，同步英文署名和素材说明。修改首屏高度时回归相邻简介区。
- 当前背景来自用户提供的 `2153815987793690624.heic`；文件实际为4928×3280 WebP，网页独立保存2400×1597 JPEG，约420KiB。仅按观察描述舷窗和地球云层，摄影者与原始来源尚未确认；英文说明链接本地署名页。旧山水 `hero.jpg` 保留在Git历史，Moments同源封面不变。Home不在运行时读取About资源，也不声明粒子表面。
- 验证：[兼容性测试记录](../../docs/modules/home.md)；改动后关注首屏文字和图片、两个入口、滚动至简介及其连续背景。

本说明使用中文；片段和数据中的网页文字使用英文。修改源文件后装配，不手改根目录生成页面。

## 当前排版（2026-10-25）

- 桌面仍为双栏：左侧按欢迎标识、姓名、正常字形研究领域、学校／研究生身份逐层排列；身份信息归入同一内容轴，不再悬浮在画面右上。右侧短标题自然换行并平衡行长，正文限制阅读宽度，主次入口紧随正文；两栏顶部对齐。桌面两组采用等宽容器（最多440px），分别靠各自外侧，局部边距为 `max(20px, var(--gutter) - 40px)`，确保左右对称；右组移动幅度应大于左组，纠正原来靠中的位置。
- `#home-title` 仅包含姓名，研究领域独立为 `.hero-discipline`；`.hero-marker` 是左栏内部的身份行。没有新增脚本或跨模块接口，背景原图、署名与两个入口保持。
- ≤760px为单列，身份→欢迎语→入口；滚动提示和摄影署名在内容下方分层排列，保留导航安全空间。手机正文16px、辅助文字至少12px；背景与首屏最小高度配对维护，避免修改一方后产生错位。

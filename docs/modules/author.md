## 兼容性测试证据

| 检查项 | 结果 | 实际范围 |
|---|---|---|
| 两集合读者 | 通过 | 独立列表、正文换行、直达 / 刷新 / 前进后退、正文与返回标题焦点；记录里的标签作为纯文本，不执行 |
| 学术类型与参考 | 通过 | Research / Learning / Seminar / Milestone；HTTPS 链接带 `noopener noreferrer`；schema 与编辑器均拒绝非 HTTPS 参考，拒绝时无 API 请求 |
| 密码门与草稿 | 通过 | 未登录没有编辑字段，错误密码在两栏均拒绝且零 GitHub 请求；正确密码立即可编辑，凭据输入处理后清空 |
| 初次连接拒绝 | 通过 | 模拟 401、非作者、错误仓库所有者、无 push 权限均不能连接；成功连接仅 GET 用户与仓库，不预读 Contents |
| 跨栏与关闭 | 通过 | Moments / Experience 及详情关闭共享当前已解锁、已连接会话，不要求重复输入；Sign out 同时锁定两处 |
| 失效连接恢复 | 通过 | Contents GET 401 清连接、保留解锁和 title / body 草稿；令牌表单重新可见，重新连接后发布成功 |
| 两栏独立发布 | 通过 | 两集合各测 409 草稿保留、重新读取最新 SHA、保留新增远端记录、PUT 仅当前路径及 main；另一集合不变，远端数据中的未知字段剥除 |
| 数据不执行与请求边界 | 通过 | 恶意登记表达式只作为数据解析后拒绝，无 PUT 或脚本执行；禁止其他文件、URL、HTTP 方法和分支，不产生请求 |
| 下载导出 | 通过 | 未连接时导出学术 `entries.js`，严格 JSON 登记解析、保留已有记录及当前草稿；无 GitHub 请求，不发布 |
| 加密记住连接 | 通过 | 未勾选 remember 不存连接，刷新上锁；选择后只存盐 / IV / 密文 JSON，原密码与令牌不进 localStorage、sessionStorage、Cookie、历史或 URL |
| 缓存刷新与篡改 | 通过 | 刷新在密码前零 API；正确密码恢复后重新 GET 用户及仓库，身份变化或密文篡改拒绝连接；错误密码不解密或请求 |
| Forget 与重新连接 | 通过 | 已连接状态下 Forget 移除缓存及当前授权而保留解锁；重新记住生成新密文；损坏缓存可 Forget，最后退出锁定 |

每个环境记录 GET `/user` 10 次、仓库 7 次、有效 Contents 读取 7 次、模拟 PUT 5 次；模拟 PUT 共 45 次，**真实 GitHub 写入合计为 0**。全部外部请求拦截，测试只使用随机密码、模拟令牌与临时双集合；HTTP 响应替换配置和数据，正式 `config.js`、`entries.js`、`posts.js` 字节保持不变（`sourceUnchanged: true`）。

## 离线与静态验证

`npm run test:author-security` 的 21 项真实 Web Crypto / 模拟请求案例通过，另覆盖独立分域密钥解密、随机盐 / IV、存储不可用及删除失败、订阅与取消竞态、401 取消并发请求、退出阻止迟到结果。离线结果与上述真实页面证据分开，不使用真实 GitHub 凭据或网络写入。

`npm run check` 通过。`npm run author:password` 的本地隐藏输入配置工具由集成验收使用临时夹具检查，只生成盐与派生校验值，不以参数传密码；这不是浏览器登录或真实发布测试。

未覆盖项：线上新版本部署、真实 GitHub 凭据 / 写入、手机真机、品牌或历史版本浏览器、外部参考实际跳转、文件方式下作者发布；浏览器存储不可用 / 删除失败只在离线案例覆盖。DOM / 存储断言不能证明浏览器堆内存或密码管理器的物理清除。

# 模块测试记录：模块名称

- 就近说明：`../../modules/<模块标识>/README.md`（填写实际位置后添加链接）。
- 入口：填写页面锚点或独立页面。
- 本次范围：简述扩展、接口或资源变化；维护说明写在模块内，避免重复。
- 测试日期与改动标识：待实测后填写。

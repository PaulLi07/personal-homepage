# 模块说明目录

每次扩展模块时，在这里新建或更新对应的简洁中文说明，并记录兼容性测试。模块范围及测试要求见 [工作协议](../WORKFLOW.md)；现有整体结构见 [框架概要](../ARCHITECTURE.md)。

复制 [说明模板](TEMPLATE.md) 为 `<模块标识>.md`，使用小写英文文件名；正文使用中文，模块的网页文字使用英文。保留用途、入口、文件与数据接口、维护方法和实际测试记录即可。

# 行内公式服务与兼容性记录

- 所属目录：[shared/math](../../shared/math/README.md)。
- 使用者：Publications 论文题名、Academic 精选论文题名。
- 入口：`Homepage.math.renderText(host, source, {fallback})`，显式 `\(...\)` 混排，普通文本与错误内容不执行 HTML。
- 依赖：本地 KaTeX 0.19.0、同版本样式与20份 WOFF2 字体；无 CDN 或外部运行时请求，MIT许可证随包保留。
- 数据兼容：新增可选 `titleTex`，原必填纯文本 `title` 保留；作者、日期、分类、路由、链接、发布和权限逻辑不变。

环境为本机 Node.js v25.8.0，运行 `node scripts/test-math.cjs`，93项断言通过。使用真实 KaTeX 和内存 DOM，覆盖当前两处题名的公式排版、数学斜体、上下标、反粒子横线、HTML与辅助 MathML、折行片段、可选字段白名单、旧数据、重复渲染、缺库/坏公式/危险指令回退、宏隔离、尺寸与展开限制、本地字体完整性，以及无 DOM 的脚本注册阶段。

离线结果不能代替浏览器字体加载和实际观感。桌面、手机模拟视口、页面导航及实际公式排版由主任务在装配后统一预览，并补充本轮兼容性记录；此处不预先将浏览器结果标记通过。其他内核、真机、线上部署和直接文件打开在本记录形成时均未测试。

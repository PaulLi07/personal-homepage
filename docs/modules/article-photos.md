## 兼容性与功能证据

| 检查项 | 实际证据 |
|---|---|
| 三格式与压缩 | 真实 JPEG / PNG / WebP 输入均转为 JPEG；2600×1400 缩到 1920×1034，尺寸与编码字节核对；每张最多 2 MiB |
| 元数据与取消 | JPEG 的 APP1 / APP13 均已剥除，返回 Blob 与字节一致；已取消操作拒绝。WebKit 自动附加这两个段的问题修复后在三视口复测通过 |
| 输入限制 | MIME / 文件头不符、超过 10 MiB、超过 4000 万像素拒绝；8 MiB 总量超限整批回滚，处理中发布与下载禁用 |
| 数据与路径 | 省略照片的旧记录兼容；六张上限、必填 alt、纯文本 caption、重复路径、外链、路径穿越与跨集合 / 跨文章拒绝 |
| 选图与键盘 | 多图预览、上下排序、删除、原生键盘与排序后的焦点保持；关闭 / 退出 / 中止处理后释放预览 URL，重开无旧照片 |
| 两栏阅读 | 含图文章直达 / 刷新正常，caption 中标签不执行；每张逐一滚入视口并等待加载 / 解码，核对实际自然尺寸及显示比例；九环境无横向溢出，页面文字为英文 |
| 下载包 | ZIP 的相对目录、中央目录、CRC32、数据登记与 JPEG 内容通过；保留旧文章及其 photos，文件不含测试密码或令牌；无发布请求 |
| 同次提交 | 两栏分别读取同版 head / tree / 数据；新树仅含当前集合数据及新图，保留旧记录与已有附图，单父提交后 `force: false` 更新 main；另一集合不变 |
| 失败与重试 | 异常 ref / blob 响应，blob / tree / commit 500，分支 409 / 422，401 与网络失败均保留草稿及照片；401 可重连；中途失败不更新分支，重试读取新 head |
| 事务与边界 | 外部 tree / commit / ref、错误基树、未本次上传 blob、新 head 后旧 blob、取消后的 blob / commit / ref 均在 fetch 前拒绝；合法上下文内越界路径、分支、方法同样拒绝 |
| 原文字发布 | 无图继续 Contents PUT，保留已有 photos，不创建照片 blob 或更新 Git ref |

每环境记录 91 次模拟请求、5 次 ref 更新尝试（3 次失败 / 不确定、2 次成功）与 1 次纯文字 PUT。模拟接口核对完整对象关系与固定路径，不能称为真实 GitHub 写入成功。

视觉检查已查看 Chromium 1440 与 390 像素的选图、Moments 图库与 Experience 图库截图：控件可用、常规字体、窄屏单列、双图实际显示；截图位于 `artifacts/screenshots/photos-*.png`。原作者浏览器 144 流程、旧功能 81 流程、基础兼容性和离线会话 21 项也已在本轮回归通过，见 [总记录](../COMPATIBILITY.md)。

独立 JPEG 解析测试另验证 ICC APP2、多扫描、转义及重启标记保留，拒绝截断、非法长度和尾随数据，范围见 [模块 README](../../modules/article-photos/README.md)。

# Apple 风格设计维护约定

用户于 2026-10-23 批准按“深色学术与摄影”的方向优化个人主页。保留简洁学术气质、宇宙粒子、摄影首屏、学术四栏目、生活叠层照片及现有博客和作者功能；通过排版、留白、材质和控件层次提高精致度。这里的 Apple 风格指克制的系统界面语言，不使用 Apple 标识，不声称与 Apple 有关联。

所有说明文档使用中文，所有网页呈现文字使用英文。模块边界遵守 [框架概要](ARCHITECTURE.md) 和 [工作协议](WORKFLOW.md)。

## 视觉约定与令牌

共享令牌定义于 `shared/base.css`，导航高度定义于 `shared/navigation/styles.css`。需要跨模块调整时先改令牌；单模块的摄影裁切、布局和内容分组留在本模块样式。

| 令牌或尺度 | 当前值 | 用途 |
|---|---|---|
| `--background` / `--surface` | `#1c1c1e` | 默认石墨灰背景与内容面板 |
| `--dark` | `#111114` | 深一层阅读空间 |
| `--surface-raised` | `#28282d` | 提升面板与选中项 |
| `--white` | `#f5f5f7` | 主要文字 |
| `--muted` | `#a7a7b0` | 次要说明 |
| `--accent` | `#9ac7ff` | 浅蓝链接、焦点和强调 |
| `--primary` | `#0071e3` | 主要操作按钮 |
| `--primary-hover` | `#0062c7` | 主要按钮悬停；与白色小字保持清楚对比 |
| `--line` | `#ffffff24` | 内部低对比边线 |
| `--gutter` | 桌面 `max(22px, 4.5vw, (100vw - 1280px) / 2)`；≤760px 为 22px；≤400px 为 18px | 页面两侧留白 |
| `--navigation-height` | 桌面 76px；≤760px 为 104px | 固定导航与锚点留白 |
| 图片与面板圆角 | 通常 16–20px | 保持图像与信息面板一致 |
| 控件圆角与高度 | 通常 10–12px，主要操作至少 44px 高 | 按钮、页签与作者表单 |

使用系统字体栈：`-apple-system`、`BlinkMacSystemFont`、`SF Pro Text`、`Segoe UI`、Arial 与系统 sans-serif，不下载外部字体。普通正文以 16–18px 为主；首页姓名桌面约 48–60px，其余标题按层级收敛，不使用窄体巨字。主要内容用冷白，辅助说明降低对比，系统蓝用于明确的操作或状态。

磨砂只用于导航和联系卡片等少量界面层；用轻边线、柔和高光与间距区分面板，不堆叠装饰。用户此前明确要求的白色主轮廓继续保持：Academic 主线 3px、预览和图片框 2px；Life 主框和照片边框 3px、副框 2px。内部资料分隔线使用低对比细线，与主轮廓区分。

同日后续Academic专题精修曾采用四张直角正方形卡片，现按用户新批准方案改为“学术探索场景”：左侧30%四行直角路牌接地，右侧约66%悬浮横向图窗，路牌顶部落在图片中部至下半部；地面配微小白色线描步行人物。图窗按5秒循环，悬停/聚焦锁定当前栏目，点击进入；减少动态效果关闭自主运动。手机改为图片在上、路牌和地面在下。图窗与路牌保留0圆角、清楚轮廓与常规字体，其他板块不改。实现拆分及参数见 [场景说明](../modules/academic/exploration/README.md)，当前验证见 [记录](modules/academic.md#academic-scene-2026-10-23)。

用户随后要求路牌与地面单独使用立体黑白漫画语言，与周围Apple风格形成反差：箭头木牌、墨线、纸面、侧板排线和草地土层；图窗与其他分区保持原视觉规则。漫画样式独立放在 `modules/academic/exploration/comic.css`，SVG为本站代码素材，选中项使用黑白反相。脚底和立柱与草地共同接地，手机裁取草图局部。验证见 [本轮记录](modules/academic.md#academic-comic-2026-10-23)。

## 模块职责

| 维护位置 | 负责内容 |
|---|---|
| `shared/base.css` | 中性色令牌、字体、基础按钮、焦点和通用进入状态 |
| `shared/navigation/` | 桌面与手机导航、滚动后的磨砂外观、当前栏目状态和公开高度 |
| `shared/details/` | 共用详情外壳、分栏、阅读宽度、返回入口与栏目页签 |
| `modules/home/` | 独立山水背景、姓名与研究领域、欢迎语和两个入口 |
| `modules/about/` | 独立人像裁切、简介、资料列表与补充说明 |
| `modules/academic/` | 分隔装饰、学术预览图与 Experience / Publications / Notes / Projects 四入口 |
| `modules/life/` | 叠层相框、散落照片与 Moments / Travels / Creations / Relationship 四入口 |
| `modules/contact/` | 用户夜景、联系卡片、外链与简短页脚 |
| 各文章、作者、附件模块 | 自己的列表、阅读或编辑样式；原业务和安全边界继续由所属模块维护 |

此次设计不把各模块合成一个大 HTML 或 CSS，不将具体内容与图片塞入共享目录。胶水继续只负责装配和初始化；所有路由、英文链接、作者入口、照片、PDF 和 Relationship 的功能边界保留。

## 图片与粒子边界

- Home 继续使用 `modules/home/images/hero.jpg` 的独立原山水图，来源为 Ivan Rohovchenko / Unsplash。
- About 的 `modules/about/images/portrait.jpg` 已由用户替换为 6240×4160 户外人像，本次样式更新不修改图片原字节；替代文本只描述可见内容，不推断人物身份、地点、摄影者或来源。它与 Home 不再是同一张图，不能用字节相同的断言约束两者。
- Contact 继续使用用户提供的 `modules/contact/images/background.png` 原图；只确认用户提供，不称为用户本人拍摄。图片归属和署名统一见 [素材清单](image-sources.md)。
- About / Academic / Life 根背景保持纯黑 `#000`，继续声明 `data-particle-surface="black"` 和前景属性；石墨灰资料卡片由所属模块提供，不改变粒子公开接口。Home / Contact 摄影背景不声明黑色粒子表面。
- 粒子保持微小、密集、清晰的白色实心点，随文档滚动，图片和公开排除区域不覆盖；不增加模糊光晕或整层鼠标视差。扩展视觉媒体时显式维护图片排除边界。

## 响应式与动效

桌面保留摄影、图文分栏与清楚的内容层级；宽度 ≤760px 时主要内容改为单栏或适当的双列入口，不能靠缩小正文挤进桌面结构。长邮箱、ORCID、附件标题和作者表单应正常换行，不产生整页横向溢出。

锚点使用公开 `--navigation-height`，Home 留白为 0，Academic 与 Life 各额外增加 16px，使分隔和相框与导航保持距离。普通导航点击要在正常滚动动画结束后检查实际遮挡，不能只以 hash 已变化作为通过依据。

动效以短距离淡入、轻微缩放和短时状态过渡为主，取消重复文字翻滚；系统减少动态效果偏好应保持可用。粒子的减少动态效果及滚动关系继续遵守 [粒子维护指南](PARTICLE-BACKGROUND.md)。

## 本轮分支与回退

本轮任务分支为 `feat/apple-homepage-design`，改版原点是 `28880ba`，独立回退分支 `backup/pre-apple-design-2026-10-23` 保留同一提交。设计改动通过检查后按工作协议整合到本地 `main`，保留任务与备份分支。本轮未推送；用户此次批准设计和本地实施，不等于授权发布到远端。

后续 Academic 精修使用 `feat/academic-science-directory`，改动前回退分支 `backup/pre-academic-science-2026-10-23` 指向 `c7cdd07`；同样只做本地维护，尚未推送，不改变下面关于用户人像的保护约定。

开始改版时用户已有的人像改动不属于本任务新增图片。其原字节另存于仓库外 `../outputs/apple-homepage-backup-2026-10-23/portrait-user-original.jpg`，补丁另存 `user-portrait.patch`；它们不作为网页资源、不加入源码包。回退样式不能顺带用 Git 备份中的旧山水图覆盖用户人像。

需要检查旧版时，先保存当前任务改动和未提交图片；优先在独立目录打开备份，避免覆盖正在维护的工作区：

```sh
git worktree add --detach ../personal-homepage-pre-apple-preview backup/pre-apple-design-2026-10-23
```

该命令得到改版前提交的独立副本，不切换或重置当前分支；其中 About 图片是该历史提交的版本。若要将“旧样式与当前人像”作为回退结果，应在回退副本中显式恢复用户人像，同时核对英文替代文本与署名，再装配、检查和预览。确认不再需要预览副本后，按 Git 正常 worktree 流程移除；不得用硬重置、强制推送或删除当前目录来回退。
